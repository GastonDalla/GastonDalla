## Hi, I'm Chicho

**Full-stack software engineer: backend, frontend and mobile.**

I design and build complete products, from backend services and APIs to web applications and native iOS and Android apps. I take them from the first commit to production and keep them running: architecture, data, payments, deployment, and the details users notice.

My work rests on clean and hexagonal architecture, test-driven development, and code that stays easy to change as a product grows.

### What I do

- **Backend:** APIs and distributed services, data modeling, authentication, payments, real-time messaging and system integrations.
- **Frontend:** fast, accessible web applications with polished interfaces and consistent design systems.
- **Mobile:** iOS and Android apps, from the first screen to releases on the App Store and Google Play.
- **Infrastructure:** containers, CI/CD pipelines, infrastructure as code and production operations.

### Featured work

#### [Ocean Anti-Cheat](https://anticheat.ac/)

A forensic screenshare platform for game servers. Ocean finds cheats by analyzing the traces they leave on a player's system, and delivers a verdict backed by evidence in about a minute. It supports FiveM, Minecraft and more than ten other games.

#### [Beepers](https://beepers.app)

An event ticketing platform for Argentina, on the web, iOS and Android. Fans buy tickets in seconds and carry them in Apple or Google Wallet. Event staff run the door from a dedicated app, connected to access-control hardware at the venue entrance.
